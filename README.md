# TikTok Live Automation Suite

TikTok canlı yayın etkileşimlerini analiz etmek, sandık ve hediye gibi bildirimleri yakalamak amacıyla geliştirilmiş, Python ve PHP tabanlı modüler otomasyon altyapısı.

## 🛠 Neler İçeriyor?
- **TikTok Canlı Yayın İzleyicisi:** mitmproxy entegrasyonu ile WebSocket trafiğini dinler.
- **Telegram Entegrasyonu:** Yakalanan bildirimleri Telegram üzerinden anlık raporlar.
- **Modüler Yapı:** Server tabanlı, düşük gecikmeli analiz sunar.

## ⚠️ Kurulum ve Güvenlik
- Proje içerisinde hiçbir API anahtarı veya kişisel veri tutulmaz.
- API anahtarlarınızı `listener.php` ve `worker.php` dosyalarındaki ilgili alanlara yerleştirin.
- Sadece eğitim amaçlıdır; kullanım şartlarına uygun hareket edilmelidir.
